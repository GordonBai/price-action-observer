# Causal PA first-version Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** A causal, auditable research-only PA engine with replay and authenticated live ingestion.
**Architecture:** Standard-library Python, immutable bar/event contracts, per-stream incremental state. Same engine for replay and webhook; generated Chinese evidence explanations, no orders or opaque win probabilities.
**Tech Stack:** Python 3.11+, unittest, SQLite, http.server, HTML/SVG.
**Spec:** docs/research/design.md

## Global Constraints
- No orders, credential configuration, paid services, public deployment or push.
- Nov17 is a known case; no true holdout claims for that day.
- Missing data prevents empirical backtest, never fabricate it.
- Default probability null; engineering approximations, not comprehensive Brooks replication.

## Review Focus
- Timezone-aware final bars, duplicate/revised/out-of-order input -> explicit rejection/idempotency.
- Gaps/session boundaries -> reset pending structures and show degraded flags.
- Pivot occurrence vs confirmation -> causal event timestamps.
- Trigger and stop in same bar -> conservative ambiguity reporting.
- Auth, payload size, untrusted text -> bounded inputs, no HTML injection.

### Task 1: Bar and engine contract
Files: pa_lens/core.py; tests/test_core.py.
Interface: Bar(symbol, timeframe, time, open, high, low, close, volume=0, source='manual') with close-time UTC ISO strings; Bar.from_dict(dict). Engine(config=None).update(Bar)->list[dict]; engine.snapshot()->dict; config immutable Config dataclass. Single stream per engine. Event fields id, family, status, direction, observed_at, evidence, anchors, probability=null, explanation, optional trigger/stop/target. Constructor rejects invalid bars.
- [x] Write and observe failing tests: validation, double-bottom candidate/confirmation delay, mirrored top, MM formula, prefix invariance, duplicate/revision handling, gaps, session reset.
- [x] Implement deterministic swings, DB/DT, frozen range breakout and MM, context and Chinese evidence.
- [x] Run whole unittest suite; commit tested scope.

### Task 2: IO, store, service
Files: pa_lens/io.py, pa_lens/service.py, pa_lens/dashboard.html; tests/test_service.py.
Consumes core interfaces. SQLite journal and replay-on-restart; POST /bar and /webhook, GET /health /snapshot / (dashboard). All endpoints authenticated with Bearer token except local dashboard shell; default localhost. Tests for rejection, dedup, restart, escaped UI and oversized body; then implement and verify.

### Task 3: Replay and evaluation
Files: pa_lens/replay.py, pa_lens/__main__.py; tests/test_replay.py.
load_bars JSONL/CSV; replay emits event tape and JSON summary; deterministic paper evaluation from confirmed setup, next-bar trigger, one position, no actual fills, conservative intrabar and gap handling, EOD exits. Cost grid. CLI replay and serve and stdin ingest. Write missing/invalid/order tests and cost/fill timing tests first. No hidden sorting of invalid chronology.

### Task 4: Documentation, data run and review
Bilingual READMEs, provenance, coverage, example synthetic bars and report command. Preserve upstream README separately. Run real data if accessible, otherwise explicit blocked report. Run full tests and compileall; independent review; fix important findings with regression tests. No publish.

Implementation scope: IO is implemented in replay.py and service.py rather than a separate io.py to keep normalization adjacent to each input contract. Baseline had no tests. See ledger and validation report for verification/limitations.
