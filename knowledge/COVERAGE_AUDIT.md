# Coverage gap audit / 覆盖缺口审计

2026-11-18. Starting inventory: 28 curated cards, not a complete PA ontology. The audit compared these with actual public official glossary entries, reviewed public sample material and CME foundations; another research contributor independently audited practical execution/product-management gaps. No new pattern code was requested or changed.

## Added after checking primary evidence

- Foundations: support/resistance; swing structure; Always In; breakout/follow-through; pullback/flag; microchannel; ii/ioi; final flag; multi-timeframe context; trend/channel lines; tight trading ranges.
- Practical boundaries: order trigger versus fill; SOXL/instrument transfer; session/liquidity; premise failure; scaling/exit policy.
- Source acquisition: Brooks official glossary direct HTTP succeeded despite web open 403. Only named entries read, not the whole page. CME support/resistance lesson text read, embedded video not watched. Practical-source scope and access details are preserved per registry entry, including search-returned official transcripts.
- Tight channel and microchannel are no longer identical aliases. Swing pivots and paper execution have partial code mappings; the other new cards do not pretend that nearby existing features implement the concept.

## Claim layers

Every card now explicitly labels `research_conclusion` as source-grounded paraphrase, `engineering_interpretation` as project synthesis (not the author's prescribed algorithm), and `open_questions` as unverified research questions. Counterexamples include original logical cautions and source examples, not automatically measured frequencies. The user permits supplementing from general knowledge; this pass could substantiate the selected gaps using primary material, so no unsupported general-knowledge definition was needed. That permission is not a reason to manufacture citations or label hypotheses as official doctrine.

## Still open, not silently completed

- Full H1–H4/L1–L4 reset rules and all inside/outside edge cases; complete MTR/final-flag variants and independently labeled charts.
- True continuous audiovisual review. Five public samples have complete caption review but only sampled frames and no heard audio; paid chapters remain unreviewed.
- News/calendar point-in-time verification; auction/open/close mechanics; exchange halts/LULD; spread, impact and borrow/short constraints.
- Dedicated tick-failure examples and near-miss execution studies. Participant intent cannot be recovered from OHLC.
- Volume/VWAP/order-flow as separate traditions, rather than mislabeling them Brooks rules.
- Triangle, ledge, broad-channel and spike-and-channel families deserve separate cards with more examples. Glossary lookup alone is not full operational mastery.
- Cross-instrument, session, corporate-action and cost-aware out-of-sample validation; known SOXL days used during design are not blind evaluation.

This audit prioritizes useful missing foundations and safety boundaries, not an assertion that all PA knowledge has now been collected. A card is a research entry, not an automatic development ticket or a validated trading recommendation.
